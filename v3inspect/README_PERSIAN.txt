نسخه ارتقایافته پیمانکاری کاظمی
================================

تغییرات این نسخه:
- پنل مدیریت با قالب سفید و سرمه‌ای.
- ویرایشگر مقاله با قالب‌بندی متن، تیتر، فهرست، نقل‌قول، رنگ، اندازه، چینش، لینک، جدول و درج تصویر بین متن‌ها.
- تصویر پس‌زمینه بخش درباره ما از تصویر ارسالی کاربر استفاده می‌کند و از پنل قابل تعویض است.
- متن‌های قابل مشاهده صفحه اصلی از بخش «اطلاعات و محتوای سایت» در پنل مدیریت قابل ویرایش شده‌اند.
- کارت‌های خدمات و نمونه‌کارها به‌صورت کامل لینک‌دار هستند و فلش‌های تزئینی حذف شده‌اند.
- دکمه‌های ثابت تماس، واتساپ و تلگرام در پایین سمت راست قرار دارند؛ شماره و شناسه‌ها از تنظیمات پنل قابل تغییر هستند.
- صفحه‌ساز بصری قبلی حفظ شده و گزینه‌های ترتیب بخش‌ها، نمایش/مخفی‌سازی، رنگ و افکت‌ها را دارد.

اجرای آزمایشی روی کامپیوتر:
1) از دیتابیس kazemi.db و پوشه static/uploads نسخه پشتیبان بگیرید.
2) در پوشه پروژه محیط مجازی بسازید:
   python -m venv .venv
3) فعال‌سازی در Linux:
   source .venv/bin/activate
4) نصب نیازمندی‌ها:
   pip install -r requirements.txt
5) اجرای محلی:
   python app.py
6) آدرس مرورگر:
   http://127.0.0.1:5000

اجرای تولیدی با Gunicorn:
   gunicorn app:app

نکته مهم درباره استقرار:
- پیش از جایگزینی نسخه قبلی، از kazemi.db و static/uploads نسخه پشتیبان تهیه کنید.
- فایل دیتابیس و پوشه آپلودها را بدون بررسی/پشتیبان‌گیری حذف یا overwrite نکنید.
- پایداری فایل‌های آپلود و دیتابیس به نوع فضای ذخیره‌سازی سرویس میزبانی وابسته است.
- این نسخه کد را برای محیط Flask/Gunicorn آماده می‌کند، اما سازگاری نهایی باید با اجرای آزمایشی روی همان سرویس میزبانی تأیید شود.
