وب‌سایت مدیریت‌پذیر پیمانکاری کاظمی — نسخه به‌روزشده
====================================================

امکانات سایت و پنل مدیریت:
- صفحه اصلی فارسی و راست‌چین، واکنش‌گرا برای موبایل و دسکتاپ
- نمایش نمونه‌کارهای ثبت‌شده از پایگاه داده
- جست‌وجوی نمونه‌کارها در سایت و پنل مدیریت
- داشبورد آماری: تعداد پروژه‌ها و درخواست‌ها و زمان آخرین درخواست
- افزودن، ویرایش و حذف نمونه‌کار همراه آپلود تصویر
- مدیریت اطلاعات شرکت، متن‌ها، تماس، آدرس و تنظیمات سئو
- ثبت و مدیریت پیام‌های مشتریان
- خروجی CSV پیام‌ها برای بازکردن در Excel (با پشتیبانی از فارسی)
- دانلود پشتیبان پایگاه داده SQLite از داخل پنل
- تغییر رمز مدیر و هش رمز با Werkzeug
- محافظت فرم‌های مدیریتی با CSRF و محدودیت تلاش‌های ناموفق ورود
- کوکی نشست HttpOnly و SameSite=Lax

نصب و اجرا در Kali Linux:
1) وارد پوشه پروژه شوید:
   cd peymankari_kazemi
2) محیط مجازی بسازید و فعال کنید:
   python3 -m venv .venv
   source .venv/bin/activate
3) وابستگی‌ها را نصب کنید:
   python -m pip install -r requirements.txt
4) برنامه را اجرا کنید:
   python app.py
5) سایت: http://127.0.0.1:5000
   پنل: http://127.0.0.1:5000/admin/login

ورود اولیه (فقط اگر پایگاه داده قبلاً ساخته نشده باشد):
   نام کاربری: admin
   رمز عبور: Kazemi-Change-This-2026!
پس از اولین ورود رمز را از بخش «تغییر رمز» عوض کنید. اگر kazemi.db قبلاً ساخته شده باشد، رمز جدید پیش‌فرض جایگزین رمز قبلی نمی‌شود.

نکات مهم:
- این نسخه برای اجرا و آزمایش محلی است؛ برای انتشار عمومی از HTTPS، SECRET_KEY ثابت و محرمانه، ADMIN_USERNAME و ADMIN_PASSWORD امن، و سرور WSGI تولیدی استفاده کنید.
- محدودیت تلاش ورود در حافظه همان پردازه است و جایگزین محدودسازی در سطح وب‌سرور نیست.
- خروجی پشتیبان شامل پایگاه داده است؛ تصاویر آپلودی در static/uploads باید جداگانه کپی شوند.
- پیش از به‌روزرسانی، از kazemi.db و پوشه static/uploads نسخه پشتیبان بگیرید.
- تصاویر نمونه اولیه تزئینی‌اند؛ عکس واقعی پروژه‌ها را از پنل اضافه کنید.
